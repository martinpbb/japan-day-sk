# Architecture

- React 19 + Vite static frontend.
- No backend, database, auth, or server runtime.
- Entry: `src/main.jsx` → `src/App.jsx`.
- Content components live in `src/components/`.
- Source data lives in `src/data/`.
- SEO helpers live in `src/seo/`.
- Static route documents are generated by `scripts/seo/generate-static-routes.mjs`.
- Important public routes include `/program`, `/ucinkujuci`, `/ucinkujuci/<slug>`, `/gastronomia`, `/vystavovatelia`, `/prakticke-informacie`, `/galeria`, `/o-podujati`, `/kontakt`.

Do not introduce React Router or a backend solely because multiple routes exist; inspect the current route handling first.
